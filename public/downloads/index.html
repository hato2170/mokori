geniusOS v1.0.0 Live ISO

ピュアホワイト・ミニマリズムデザインのAndroid-x86_64ベースカスタムOS。Surfaceの電源ボタンによるスリープ（Deep Sleep）、タッチパネル・ボタン・WiFiドライバーを完全統合した実機ブート用イメージです。

ファイル形式 Bootable Hybrid ISO (.iso)
ファイルサイズ 965.7 MB (965,738,496 バイト)
対応アーキテクチャ x86_64 (Intel / AMD / Surface)
ブート方式 UEFI (Surface推奨) / BIOS 両対応
📥 geniusOS ISO を直接ダウンロード
🚀 Surface / PC 実機起動・USB書き込み手順
1
上の青いボタンを押して geniusos-v1.0.0-x86_64.iso をPCにダウンロードします。
2
Rufus（無料ツール: rufus.ie）を開き、USBメモリを選択して上記ISOを指定。「スタート」を押して書き込みます。
3
Surfaceの電源を完全にオフにし、作成したUSBメモリを挿します。
4
「音量を下げるボタン（-）」を押したまま「電源ボタン」を押し、Surfaceのロゴが出たら音量ボタンを離します。
5
起動メニューから Run geniusOS (Pure White Mode) または Surface Mode を選択すれば、Windowsを消さずにUSBから直接geniusOSが立ち上がります！
